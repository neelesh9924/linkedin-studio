{# ───────────── 2. what a job looks like ───────────── #}

When Claude is working

Every button that runs Claude behaves the same way.
  1. {{ icon("sparkle", 16) }}
    You press a buttonPlan the week, Draft this, Run the audit, any tool, or a chat message.
  2. {{ icon("clock", 16) }}
    It waits its turnClaude does one job at a time. Others queue behind it.
  3. {{ icon("book", 16) }}
    Claude worksIt loads the skill, reads your Story Bank and the skill's reference files, then writes. You see each step and a timer.
  4. {{ icon("check-circle", 16) }}
    The result appears in placeNo reload. If you went to another page, a notice with an Open link finds you.
Nothing real happens. No Claude run, nothing saved.
The job's card will appear here.

Cancel stops a job at once. A run that passes {{ cfg.timeout_seconds }} seconds is stopped for you, and Try again repeats it.
